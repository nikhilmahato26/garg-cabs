## 🛠️ Tech Stack

- **Framework:** React 18 with TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom brand palette: Navy `#071D3B`, Deep Navy `#06152D`, Red `#C71925`, Yellow `#FFC928`, Gold `#D4AF37`)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Forms & Validation:** React Hook Form + Zod
- **SEO:** Metadata & Schema.org LocalBusiness JSON-LD

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/nikhilmahato26/garg-cabs.git

# Navigate to project
cd garg-cabs

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
